# startups.b: learnings

- Check a relayed decision at its source (the person's own words, the signed record) before acting. On 23 Nov two relays misstated decisions (asks 14 and 31); the records said otherwise.
- A person's consent is their own word. Public commit history is not consent to be featured.
- Copy built images (design thumbnails, share card) with every build; stale ones showed removed content.
- Measure the live page, not only the local build: live heights ran about 60 px taller.
- A site address that carries a name names that person; an "unnamed listing" of it is not possible.
